# UI 说明：译站

- **谁在什么时刻打开**：给反复翻产品帮助文档的小团队。
- **首屏任务句**：这一段，术语译对了吗。
- **主操作**：按「贴原文分段 → 锁词表与变量 → 导出双语稿」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：双语排版校样；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：双语排版校样。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给反复翻产品帮助文档的小团队：按段对齐，锁定项目词表、数字、链接和变量；改一次术语，先看受影响的段落，再决定同步。
